# InsightAnalyst

An AI-powered analytical agent built in Python designed to process knowledge bases, enforce data contracts, and generate actionable insights.

## Project Structure

InsightAnalyst/
├── agent/          # Core agent logic and execution pipelines
├── knowledge/      # Knowledge base resources and domain context
├── tests/          # Automated test suite
├── contracts.py    # Data schemas and interface contracts
├── requirements.txt# Python dependencies
└── .env.example    # Environment variable template

Setup & Installation


1.Clone the repository
    git clone [https://github.com/nyx-suk/InsightAnalyst.git](https://github.com/nyx-suk/InsightAnalyst.git)
    cd InsightAnalyst

2. Create and activate a virtual enviroment
  python -m venv venv
  source venv/bin/activate  # On Windows: venv\Scripts\activate

3.Install dependencies
  pip install -r requirements.txt

4. Configure enviroment variables
   cp .env.example .env
